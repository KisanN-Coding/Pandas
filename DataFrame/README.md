# DataFrame

This contains well-structured Jupyter notebooks and datasets to help you understand and practice **Pandas DataFrame operations** — from basic concepts to advanced techniques.

**Here is a brief description of each folder :**

### 1️⃣ **DataFrame_Fundamentals**

Covers the **basics of Pandas DataFrame**, including:

- Creating DataFrames from different sources  
- Selecting, indexing, and slicing data  
- Adding, modifying, and deleting rows or columns  
- Handling missing values  

---

### 2️⃣ **GroupBy-and-Merging**

Includes **grouping and merging techniques**:

- Using `groupby` for aggregation and transformations  
- Pivot tables and cross-tabulations  
- Merging and joining multiple DataFrames  
- Concatenation for data combination  

---

### 3️⃣ **MultiIndex**

Explores **multi-level indexing (hierarchical indexing)**:

- Creating and managing MultiIndex objects  
- Advanced indexing and slicing techniques  
- Aggregation with multi-level indices  
- Reshaping data with `stack` and `unstack`  

---

### 4️⃣ **Strings_Operations**

Demonstrates **string vectorized operations**:

- Cleaning and manipulating text data  
- Applying regex-based transformations  
- Splitting, joining, and extracting text patterns  
- Handling case conversions and whitespace issues  

---

### 5️⃣ **Date_Time**

Focuses on **date and time operations** such as:

- Parsing dates in datasets  
- Extracting components (year, month, day, etc.)  
- Performing arithmetic and comparison operations  
- Resampling and time series analysis
